# Fast Media Organizer (파일 정리기)

> **Q-Dir 스타일의 효율적인 분할 탐색 뷰**와 **키보드 중심의 초고속 사진/동영상 분류(이동/복사)**를 제공하는 강력한 데스크톱 애플리케이션입니다.

---

## 🌟 주요 특징 (Key Features)

### 1. 직관적인 4대 분할 섹션 레이아웃 (Q-Dir 스타일)
- **1. 좌측 폴더 트리**: Windows 드라이브(`C:\`, `D:\` 등)와 디렉터리 계층 구조를 트리로 표시. 클릭하여 탭으로 열기, 새 폴더 생성, 타겟 폴더로 드래그 지원.
- **2. 중앙 상단 타겟 폴더 (1~9번 슬롯)**:
  - 드래그 앤 드롭으로 자주 사용하는 분류 폴더를 1~9번 슬롯에 매핑.
  - **1초 하이라이트 애니메이션 피드백**: 단축키로 파일 이동/복사 시 대상 슬롯 카드가 **1초간 테두리 발광 + `+1 이동됨/복사됨` 플로팅 배지**를 표시하여 어느 폴더로 갔는지 직관적으로 확인.
- **3. 중앙 하단 폴더 내용 (멀티 탭 지원)**:
  - **Q-Dir 스타일 멀티 탭**: 탭 추가/닫기/이동 및 복원 지원.
  - **자세히 보기 vs 썸네일 보기**: 표 형식 정렬 뷰와 실시간 크기 조절 슬라이더가 포함된 썸네일 바둑판 뷰 지원.
  - **상위 폴더 이동(`FolderUp`) 및 새 폴더 생성(`FolderPlus`, `Ctrl+N`)** 버튼 제공.
  - **경로 직접 입력/복붙 네비게이션**: 경로 표시줄을 클릭하여 복사한 경로를 붙여넣고 `Enter`를 누르면 즉시 이동.
  - **자동 다음 파일 선택**: 파일을 타겟 폴더로 이동시키면 목록에서 즉시 다음 파일이 자동 선택되어 연속 작업 가능.
- **4. 우측 미디어 미리보기**:
  - **고해상도 사진 뷰어**: 맞춤 보기, 줌 인/아웃, 90도 회전 지원.
  - **커스텀 동영상 플레이어**:
    - 커스텀 인터랙티브 타임라인(Seek Bar) 및 시간 표시(`01:23 / 05:40`).
    - 3단계 시간 건너뛰기 오버레이 인디케이터(`+5s`, `-15s`, `+60s`).
    - 음소거(Mute) 및 볼륨 상태 영구 유지.
  - **포커스 가드(Focus Guard)**: 타임라인을 클릭·드래그하거나 볼륨을 조절한 직후에도 방향키나 1~9번 핫키가 포커스를 뺏기지 않고 즉시 동작.

### 2. 프리셋 (Preset) 저장 및 복원
- 현재 작업 중인 **폴더 경로**와 **타겟 폴더 슬롯 1~9번 구성**을 프리셋으로 저장(예: *"2024 여행사진 정리"*, *"유튜브 소스 분류"*).
- 앱을 껐다 켰을 때는 깔끔하게 기본 경로(`C:\`)로 시작하며, 상단 **프리셋 메뉴**에서 원하는 구성을 클릭 한 번으로 즉시 복원 가능.

### 3. 드래그 앤 드롭 파일 이동 확장
- 폴더 내용 창의 파일/폴더를 마우스로 끌어서 **타겟 폴더 슬롯**에 드롭하여 즉시 이동.
- 폴더 내용 창의 파일을 좌측 **폴더 트리의 특정 폴더**로 드래그 앤 드롭하여 바로 이동 가능.

### 4. 작업 취소 (Undo, `Ctrl+Z`) & 파일 충돌 처리
- 이동 또는 복사한 작업을 `Ctrl+Z` 단축키나 상단 Undo 버튼으로 즉시 안전하게 되돌림.
- 대상 폴더에 동일 파일명이 존재할 경우 **덮어쓰기 [1/O]**, **건너뛰기 [2/S]**, **파일명 자동 수정 [3/R]** 팝업 모달 제공 (설정에서 기본 동작 지정 가능).

### 5. 다크 모드 / 라이트 모드 테마 지원
- 상단 툴바의 해/달 아이콘 버튼(`Sun / Moon`)을 클릭하여 언제든 다크 테마와 라이트 테마를 즉시 전환.

## ⌨️ 단축키 안내 (Hotkeys)

모든 핵심 단축키는 **설정(Preferences) > 단축키 설정**에서 복수키 조합(`Ctrl`, `Alt`, `Shift` 등)을 포함하여 사용자가 원하는 키로 재맵핑할 수 있습니다.

| 기능 | 기본 단축키 | 설명 |
| :--- | :--- | :--- |
| **타겟 폴더로 이동** | `1` ~ `9` | 선택한 파일을 해당 번호의 타겟 폴더로 즉시 이동 (다음 파일 자동 선택) |
| **타겟 폴더로 복사** | `Ctrl + 1` ~ `Ctrl + 9` | 선택한 파일을 해당 번호의 타겟 폴더로 즉시 복사 |
| **빈 슬롯 순차 자동 배치** | `Ctrl + ↑` | 선택한 폴더를 타겟 폴더 1~9번 중 비어있는 첫 슬롯에 자동 등록 |
| **파일 탐색 이동** | `↑` / `↓` / `←` / `→` | 폴더 내용 목록에서 이전/다음 파일 선택 (미리보기 즉시 갱신) |
| **상위 폴더로 이동** | `Alt + ↑` | 현재 폴더의 상위(부모) 폴더로 이동 |
| **새 폴더 만들기** | `Ctrl + N` | 현재 폴더에 새 폴더를 만들고 이름 변경 모드로 진입 |
| **이름 바꾸기** | `F2` | 선택한 파일 또는 폴더의 이름 변경 |
| **새로고침** | `F5` | 현재 폴더 내용 다시 불러오기 |
| **실행 취소 (Undo)** | `Ctrl + Z` | 직전 이동/복사 작업 되돌리기 |
| **동영상 재생 / 일시정지** | `Space` | 동영상 미리보기 재생 또는 정지 |
| **동영상 음소거 토글** | `M` | 음소거 켜기 / 끄기 |
| **동영상 X초 건너뛰기** | `Ctrl + ← / →` | 기본 5초 앞/뒤로 이동 (설정에서 초 변경 가능) |
| **동영상 Y초 건너뛰기** | `Shift + ← / →` | 기본 15초 앞/뒤로 이동 (설정에서 초 변경 가능) |
| **동영상 Z초 건너뛰기** | `Ctrl + Alt + ← / →` | 기본 60초 앞/뒤로 이동 (설정에서 초 변경 가능) |
| **새 탭 열기** | `Ctrl + T` | 새 탐색 탭 열기 |
| **현재 탭 닫기** | `Ctrl + W` | 현재 활성화된 탭 닫기 |
| **오른쪽 탭으로 이동** | `Shift + Tab` | 다음 탭으로 이동 |
| **왼쪽 탭으로 이동** | `Ctrl + Shift + Tab` | 이전 탭으로 이동 |
| **닫은 탭 다시 열기** | `Ctrl + Shift + T` | 마지막으로 닫았던 탭 복원 |

## 🛠️ 기술 스택 (Tech Stack)

- **Runtime & Desktop Framework**: Electron 44, Node.js 24
- **Frontend Core**: React 18, TypeScript, Vite (`electron-vite`)
- **Styling**: Tailwind CSS v4, Lucide React Icons
- **State Management**: Zustand
- **Media Streaming**: 커스텀 Range Request 프로토콜 (`media://`) 구현으로 대용량 4K 비디오 및 고화질 이미지 즉각 스트리밍
- **Packager**: Electron-Builder

## 🚀 개발 및 빌드 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 모드 실행 (핫 리로드 지원)
```bash
npm run dev
```

### 3. 자동화 테스트 실행
```bash
npm test
```

### 4. Windows 실행 파일 빌드
```bash
npm run build:unpack
```
빌드 완료 후 `dist/win-unpacked/fast-media-organizer.exe` 파일이 생성됩니다.
